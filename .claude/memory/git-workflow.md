# Git workflow

- Commit and push straight to `main` (see `.claude/CLAUDE.md`). GitHub Pages publishes
  from `main`, so a push there goes live within a minute or two.
- A branch `claude/gracious-cerf-3qw21c` exists from the first setup session. It is no
  longer used and can be deleted.
- Deleting remote branches from a Claude cloud session is refused (HTTP 403 from the
  git proxy). Benja deletes them on GitHub instead: Code → Branches → trash icon.
  `claude/sleepy-gauss-ej5nj0` (Nov 2026 session) is also unused and can be deleted.
